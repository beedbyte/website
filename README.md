# Beedbyte website

![Beedbyte pixel mark](assets/beedbyte-mark.svg)

[beedbyte.tech](https://beedbyte.tech) is the public home for Beedbyte's mathematical notes and software projects. The site is available in English, German, and Simplified Chinese. Research records show their sources, scope, and previous versions so readers can follow what changed.

Start with the [research projects](https://beedbyte.tech/research), [software projects](https://beedbyte.tech/projects), [publications](https://beedbyte.tech/publications), or [profile links](https://beedbyte.tech/links). The [Beedbyte GitHub organization](https://github.com/beedbyte) hosts separate repositories for Rule 30, graceful spider trees, Schur-number checks, and SHA-256 project notes.

This repository describes the public website and carries its brand mark. It contains no server code, deployment configuration, private content, or account data.

## Research records and versions

The [Graceful research note](https://beedbyte.tech/publications/growing-prescribed-zero-depths-equal-arm-spiders) presents the published construction of a growing set of prescribed zero depths in equal-arm spiders, with its proof and reproduction archive. Research records link earlier versions and describe changes to mathematical statements, assumptions, evidence or software.

Die Forschungsseiten führen frühere Fassungen auf und beschreiben Änderungen an mathematischen Aussagen, Voraussetzungen, Nachweisen oder Software.
