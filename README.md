# Beedbyte website

![Beedbyte pixel mark](assets/beedbyte-mark.svg)

[beedbyte.tech](https://beedbyte.tech) is the public home for School Scotty's mathematical notes and software projects. The site is available in English, German, and Simplified Chinese. Research records show their sources, scope, and previous versions so readers can follow what changed.

Start with the [research projects](https://beedbyte.tech/research), [software projects](https://beedbyte.tech/projects), [publications](https://beedbyte.tech/publications), or [profile links](https://beedbyte.tech/links). The [Beedbyte GitHub organization](https://github.com/beedbyte) hosts separate repositories for Rule 30, graceful spider trees, Schur-number checks, and SHA-256 project notes.

This repository describes the public website and carries its brand mark. It contains no server code, deployment configuration, private content, or account data.

## Site update · 8 October 2026

The version tables now show change descriptions in English, German, and Simplified Chinese, including older research versions. Older Graceful note claim metadata is translated in the German and Chinese archive views. The [methods page](https://beedbyte.tech/methodology) and research pages distinguish editorial responsibility from documented AI contributions to research, code, drafts, translations, and checks. Affected archive views mark corrected attribution wording; the stored revision snapshots and checksums remain unchanged. This update does not change mathematical claims.
